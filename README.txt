STOCKNOVA INVENTORY MANAGEMENT SYSTEM

1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run: python -m pip install -r requirements.txt
4. Run: python -m streamlit run app.py
5. The browser opens at http://localhost:8501

The app creates inventory.db automatically. Demo products are seeded on first launch.
Syntax check: passed with Python py_compile.
